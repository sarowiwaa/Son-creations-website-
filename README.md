Son Creation — Web Design & Digital Solutions

Your Vision, Our Creativity.

Son Creation is a responsive business website designed to showcase digital services, connect with potential clients, and help businesses establish a professional online presence.

The website features a modern navy-blue, gold, and white design, bilingual content in English and French, and direct WhatsApp communication for enquiries and quotations.

🌐 Features

- Responsive Design: Optimized for mobile phones, tablets, and desktop screens.
- Bilingual Support: Switch between English and French using the language selector.
- Website Design Services: Showcase website development and design services.
- Graphic Design: Promote branding, posters, flyers, and promotional materials.
- Social Media Content: Present creative content services for businesses.
- Brand Identity: Highlight professional branding solutions.
- Website Maintenance: Advertise website updates and improvements.
- Digital Consultation: Allow clients to discuss their digital needs.
- Pricing Packages: Present Starter, Professional, and Custom Project options with quotation requests.
- FAQ Section: Answer common questions about services and pricing.
- WhatsApp Integration: Enable direct enquiries and customized quotation requests.
- Dynamic Copyright Year: Automatically display the current year.
- SEO Metadata: Include page titles, descriptions, and theme color settings.
- Accessibility Features: Use semantic HTML, accessible navigation labels, and button states.

🛠️ Technologies Used

- HTML5 — Website structure and content.
- CSS3 — Styling, responsive layouts, colors, animations, and visual presentation.
- JavaScript — Language switching, WhatsApp links, dynamic page metadata, and copyright year updates.

The website uses vanilla HTML, CSS, and JavaScript. No external frameworks or package installations are required.

📁 Project Structure

Organize the project files as follows:

son-creation/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    └── site.js

Note: The supplied code currently combines HTML, CSS, and JavaScript in a single HTML file. The structure above is an optional organization for separating the styles and scripts into their own files.

If you keep everything together, you only need "index.html" and "README.md".

🚀 Getting Started

1. Download or Clone the Project

If the project is hosted on GitHub, clone it using:

git clone YOUR_REPOSITORY_URL

Alternatively, download the project files to your computer.

2. Open the Website

Open "index.html" in a modern web browser to view the website locally.

3. Configure WhatsApp

The WhatsApp contact number is defined in the JavaScript section:

const WHATSAPP_NUMBER = "254740868638";

Replace the number with your business WhatsApp number in international format, using digits only and without the "+" symbol.

4. Test the Website

Check the following features before publishing:

- Navigation links scroll to the correct sections.
- The English and French language buttons update the website content.
- WhatsApp buttons open the correct chat.
- Quotation buttons include the selected package in the message.
- The website displays correctly on mobile and desktop.
- The FAQ items expand and collapse correctly.

💬 WhatsApp Integration

WhatsApp is the primary contact channel. Messages are generated dynamically based on the selected language and, where applicable, the chosen pricing package.

Example English message:

«Hello, I would like a quote for Professional.»

Example French message:

«Bonjour, je souhaite obtenir un devis pour l'offre Professionnel.»

WhatsApp links open in a new tab, allowing visitors to contact Son Creation directly.

🌍 Language Support

The website supports:

- English (EN): Default language.
- French (FR): Alternative language.

Translations are stored in a JavaScript object. To update translated content, edit the corresponding keys in the "translations" object.

🔒 Privacy and Security

The website does not currently include a backend, database, account system, or online payment processing. Contact requests are initiated through WhatsApp.

Avoid placing private credentials, API keys, or sensitive client information in public website code.
